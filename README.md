# Mb2 Builder – Live Page Builder for Moodle

Mb2 Builder is a modern visual page builder for Moodle that allows you to create and edit content directly inside Moodle without coding.

It is designed for the **New Learning Moodle theme (theme_mb2nl)** and provides a fast, intuitive way to build responsive pages and manage content across your site.

---

## Overview

Mb2 Builder allows administrators and content editors to build and edit Moodle page content visually inside the browser.

It extends Moodle’s Page resource and layout system and works with:

- Moodle front page
- Pages added to the front page
- Course Page resources

With Mb2 Builder, you can design and update Moodle content in real time, without switching between code, templates, or external tools.

---

## Key Features

### Live editing
Edit page content directly in real time with instant visual feedback.

### Import pre-built layouts
Import ready-made layouts into new or existing Moodle installations and customize them to match your design needs.

### Unlimited pages
Create unlimited pages such as:
- Front page
- About us
- Services
- Contact
- Landing pages
- Custom course pages

### Multi-language content support
Create separate sections or rows for different languages within a single page layout.

### Conditional content display
Show or hide content based on user login status:
- Guests
- Logged-in users

### Import / export layouts
Export your custom layouts and reuse them across different pages or Moodle installations.

## Features Highlights

- Visual page builder (no coding required)

- Works on front page and course pages
- Fully responsive layouts

## Requirements

- Moodle 4.0 - 5.3+
- New Learning Moodle theme (theme_mb2nl)
  - https://lmsstyle.com/theme/new-learning/

---

## Important

This plugin is designed exclusively for use with the **New Learning Moodle theme**.  
It is not intended for use with other Moodle themes.
