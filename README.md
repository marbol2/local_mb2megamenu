# Mb2 Mega Menu

Mb2 Mega Menu is a customizable navigation plugin for Moodle, designed exclusively for the **New Learning Moodle theme (`theme_mb2nl`)**.

It allows administrators to create, organize, and customize hierarchical menu structures with an intuitive visual builder. Configure menu items, icons, images, multilingual labels, and other navigation options to create a responsive navigation experience tailored to your Moodle site.

---

## Overview

Mb2 Mega Menu extends the navigation capabilities of the New Learning Moodle theme, making it easier to build and manage custom menus without editing theme templates or writing code.

Create multi-level navigation menus, organize nested items using drag-and-drop controls, and customize the appearance and behavior of individual menu items.

---

## Requirements

- Moodle version supported by your installed New Learning theme (`theme_mb2nl`)
- New Learning Moodle theme

**Get the New Learning theme:**  
https://lmsstyle.com/theme/new-learning/

---

## Important

Mb2 Mega Menu is designed exclusively for the **New Learning Moodle theme (`theme_mb2nl`)**. It is not intended for use with other Moodle themes.
